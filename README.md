<pre>
  
OCalc is a simple yet advanced calculator which runs in a CLI environment and is planned to have multiplatorm support in the future. OCalc has support for many different functions including simple mathematics, geometry, central tendencies, and much much more is planned for the future. If you have any suggestions for features to be added, do not hesitate to leave a recommendation or contribute the code yourself, or if you want to note a bug or miscalculation. (You will even be credited for the support!)

One major to thing to note is that this project was made to test my abilities in Python, I am a beginner developer pushing 5 weeks on working with Python, as such bugs and issues will be prominent in the code. This program was primarily released in order to seek evaluation and to publish something which shows my current skills while not being useless or just a game. (If you want to play a game, check out Maze-Game on my GitHub profile.

OCalc currently supports several functions and commands including;

HELP - list available commands
QUIT - Quit/Exit Program
ABOUT - Information about the program
CLEAR - clear screen
MLOAD - Load from Memory
MSAVE - Save to Memory
MUL - Multiply
DIV - Divide
SUB - Subtract
ADD - Addition
ROOT - Root Extraction
EXPO - Exponentiation
PERC - Percentage
AVRG - Average Number
MEDN - Median Number
RAND - Random Number
TRIG - Trigonometry
PYTH - Pythagorian Theorem
AREA - Find Area
PERI - Perimeter
VOLU - Find Volume
SURA - Find Surface Area

With more being planned in the future.
